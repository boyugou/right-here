# Roadmap

## Working

- Core: actions, planner, config, menu, catalogs, path styles, quoting (with real-shell tests).
- `rh`: run, actions, menu, agents, apps, config, init, install, uninstall, docs, doctor.
- Terminal adapters: Ghostty, Terminal.app. Agent launchers: typed, terminal link, desktop app.
- The app and the Finder extension; installer; `rh doctor`.

## Next

- Services / Quick Actions generated from the config (covers iCloud Drive, gives keyboard shortcuts).
- MCP server over the action registry; `rh finder selection`; Claude Code plugin with skills.
- Localization: String Catalogs, about thirty languages, a verifier and a translation workflow.
- Notarized DMG, Homebrew cask and formula, CI.
- Adapters for iTerm2, WezTerm, kitty, Alacritty, Warp, cmux (documented, to be checked on real installs).
- A menu-only App Store build.

## Open

- Which process the Automation prompt names; the items, sidebar and toolbar menus on a real run.
- Whether Quick Actions appear on a folder background.
