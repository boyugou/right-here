# Homebrew templates

`right-here.rb` (a cask for the app) and `rh.rb` (a formula for the command-line tool alone) are templates for a
tap. Their checksums are placeholders (`REPLACE_WITH_THE_SHA256_OF_THE_DMG` and similar): fill in the version and
`sha256` from the release's `.sha256` file when publishing a release. See
[`docs/development/RELEASING.md`](../../docs/development/RELEASING.md).
